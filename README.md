# Krillion (clone)

A fan-made clone of the daily trivia game Krillion: answer a prompt, and the **rarer** your answer, the deeper you dive. Reach 7,000 m in 7 rounds.

- Single-file game (`index.html`), no dependencies, works offline and on phones.
- 35 prompts with hand-written answer-frequency tables (estimates, not real player data).
- Daily dive (same prompts for everyone each day) and random dive.
- Desktop build: wrapped with pywebview + PyInstaller into a Windows `.exe`.

All code is original; no assets from the original game are used.

## Play
Open `index.html`, or use the GitHub Pages link once enabled.
